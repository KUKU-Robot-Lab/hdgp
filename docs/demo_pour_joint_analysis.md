## 의심 사항 (URDF/USD 해석 오류 가능성)

warm state bank (grasp 직후)와 demo pour 간에 j1, j3, j5가 **부호 반전**됨.  
이는 두 가지 중 하나일 가능성:

1. **다른 IK 해 branch**: 동일한 end-effector 위치에 대해 팔꿈치 위/아래 등 다른 관절 구성 사용
2. **관절 부호 규약 차이**: URDF/USD에서 joint axis 방향이 다르게 해석되어 부호가 반전됨

→ sim articulation으로 각 joint를 +방향/−방향으로 직접 움직여보면 구분 가능.
