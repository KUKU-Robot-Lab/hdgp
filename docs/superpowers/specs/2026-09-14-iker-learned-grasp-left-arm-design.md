## 1. 왜 바꾸나

사람 기준선(구성 0·오른팔 `tesollo_right_short`·K1 스크립트 파지 뱅크)을 250 epoch 학습한 체크포인트를 결정론으로
평가했다(512 env·env 마다 첫 에피소드·2026-09-14).

| 측정 | 값 |
|---|---|
| 스펙 성공(에피소드 끝 평균 키포인트 거리 ≤ 5 cm) | **26.8 %** (TensorBoard 스냅샷 35.9 % 는 성공률이 아니다) |
| 실패 중 "신발이 손을 떠나 받침 위에 방향 틀린 채 놓임" | 350 / 375 (93 %) |
| 신발이 손바닥을 벗어나는 스텝(실패 env) | 중앙값 10, q90 20 / 200 |
| 신발 마찰 0.3~1.8 사분위별 성공 | 0.31 / 0.27 / 0.26 / 0.23 (상관 −0.06) |
| 신발 질량 0.04~0.27 kg 사분위별 성공 | 0.41 / 0.34 / 0.17 / 0.15 (상관 −0.24) |

영상(`log/.../iker_human_c00_k1/videos/play/rl-video-step-0.mp4`)에서 신발은 스텝 10 무렵 받침 +y 옆 모서리를 넘다 옆으로
뒤집혀 손에서 빠진다. 옮길 신발은 로봇 **왼쪽**(y +0.136)에 있고 목표는 받침 +y 가장자리 안 4.5 cm 다. 오른팔은 몸
중앙을 넘어 신발을 집고 받침 옆면을 끌어 올려야 한다.

사용자 결정(2026-09-14):
1. IKER 원형 유지 — 보상 5항 고정, VLM 은 목표 코드만, "반복"은 단계마다 새 관측으로 재질의(논문 III 절·Algorithm 1).
2. 옮기는 팔을 **왼팔**(`tesollo_left_short`)로 바꾼다.
3. 비전 재질의 루프는 계획 3 에 넣는다.
4. K1 스크립트 파지 대신 **파지부터 학습**한다 — 2단계: 파지 정책 → IKER 정책.
5. 2단계 IKER 정책의 손은 1단계 파지 목표에 **고정**하고 행동은 팔 6차원(원본 IKER 과 같다).
6. 1단계는 IKER 신발 장면 + 손바닥 6D IK + 손 20관절로 만든다.
7. 1단계 성공 높이는 **5 cm** — 받침 모서리 넘기기는 2단계가 배운다.
8. reward-audit 수정(§12)을 확인하고 진행한다.

## 5. 파지 품질 q

- 손가락마다 마디 링크 `<side>_hl_<f>_3`·`_4`·`_tip`(프로필 `finger_sensor_bodies`)의 위치에서 신발 표면점(`shoe_meta.json`
  `hull_local` 1,776점에서 균일 간격으로 256점 고정 추출)까지 **최근접 거리** d_l.
- 커널 k_l = exp(−d_l / 0.02), 손가락 평균 w_f, 5손가락 soft-min(τ 0.1), 손바닥 법선(프로필 `palmar_axis_local`, 손바닥
  링크 기준)이 신발 중심을 향할 때만(cos > 0). grasp_fj `grasp_quality` 의 원통 거리(e_xy·e_z)를 최근접 거리로 바꾼 것이다
  (신발은 축대칭이 아니다).
- g(q) = 0.5 + 0.5·clip((q − q_lo)/(q_hi − q_lo), 0, 1).
- **q_lo·q_hi 는 학습 전에 신발에서 잰다**(관찰 대조 12행): 새로 만든 왼팔 K1 뱅크의 채택 상태에서 q 를 계산해 q_lo = p25,
  q_hi = p90 으로 정하고 값과 분포를 기록한다. 학습 ep 300 무렵 정책의 성공 순간 q 분포로 다시 확인한다(자동 사다리 금지).
- 연산량: 4096 env × 15 마디 × 256 점 = 1,570 만 거리/스텝 — 부팅 스모크에서 fps 를 잰다.

## 6. 1단계 보상·종료

**자유 들기 높이** dz_free = 신발 hull 최저점 z − 에피소드 시작 시 최저점 z. 신발 hull 256점의 xy 가 받침 영역을
**1 cm 여유**로 넓힌 사각형(x 0.10~0.44, y ≤ 0.04)과 하나라도 겹치면 **0** 으로 둔다 — 받침에 밀어 올리거나 옆면에 기댄
높이를 들기로 세지 않는다.

**잡힘** held = dz_free ≥ 0.05 ∧ 손바닥–신발 중심 거리 ≤ 0.15 m ∧ |신발 속도 − 손바닥 속도| < 0.05 m/s.

| 항 | 식 | 비고 |
|---|---|---|
| palm_progress | 50 × (손바닥–신발 표면 간극의 에피소드 최단거리 갱신분), 래치 전 | 진행형, 에피소드 예산 ≈ 50 × (시작 간극 − 접촉 간극) ≤ 5 |
| lift_progress | 2000 × (clamp(dz_free, 0, 0.05) 의 에피소드 최고치 갱신분), 래치 전 | 진행형, 총액 100 |
| lift_bonus | 300 × g(q), **잡힘 3 연속 스텝** 순간 1회(래치) | 한 프레임 튕김으로 못 받는다 |
| success_bonus | 1000 × g(q), 잡힘 20 연속 스텝 ∧ 신발 속도 < 0.05 m/s 순간 1회 → 종료(terminated) | 끊기면 카운터 0 |
| hand_floor | −10 × (테이블 + 1 cm 아래 손 최저점 깊이), 스텝당 상한 5 | |
| arm_vel · hand_vel | **0**(첫 런). Σ\|q̇\| 원시값만 로깅 | 과제 전 억제 항 금지 |

- 잘림(truncated): 120 스텝, value bootstrap. 종료: 성공, 또는 신발이 테이블 아래로 떨어짐(z < 0.10) — 벌점 없음.
- 무행동 수입 = 0(상수 항 없음). 평손(g 0.5)으로 스텝 40 에 래치, 60 에 성공하면 할인 가치
  ≈ 0.99⁴⁰·(100 + 150) + 0.99⁶⁰·500 ≈ 441. 좋은 파지(g 1.0)는 ≈ 883.
- 래치 뒤 유지 구간의 스텝 수입은 0 이고 성공까지 기다리면 1000·g·0.99²⁰ ≈ 818·g — "보너스만 받고 놓기"보다 유지가 낫다.
- 부팅·스텝 로깅(관찰 대조 17행): γ, 무행동 스텝 수입(0 이어야 함), palm_progress 예산, 보상 항별 값, q·손가락별 w_f·손바닥
  cos, dz_free, 잡힘 카운터, 래치 스텝, 받침 겹침 비율(해킹 감시), 팔·손 Σ|q̇|, 손 목표 스텝 이동량.

## 7. 학습 파지 뱅크 (계획 2c)

- 1단계 체크포인트를 결정론으로 롤아웃하고 성공 순간의 전 관절 위치·관절 목표(팔 = 현재 자세, 손 = EMA 목표)·신발 자세·
  손바닥 자세를 기록한다.
- 기존 `make_grasp_bank.py` 의 재현 들기 검증(상태 복원 → 손 고정 → 10 cm 들기 → 1 s 유지, 신발–손바닥 상대 변화 < 1 cm)을
  통과한 것만 넣는다. 최소 64 개.
- `grasp_bank.json` 스키마·부팅 대조(`robot_usd`·`shoe_meta_sha256`·`scene_config`·게인)는 그대로다. `metadata.source =
  "learned_grasp"`·체크포인트 경로·sha256·1단계 보상 버전을 더한다.
- 함정: 관절 열은 **이름**으로 정렬하고(열 순서 스크램블 이력), 1단계와 2단계는 같은 게인·같은 자산이어야 한다(웜 상태는
  게인과 한 묶음). 부팅 대조가 게인을 검사한다.

## 8. 2단계 IKER 정책 (계획 2c)

- 기존 `IkerShoeEnv` 그대로: 행동 6D, 손 = 뱅크 손 목표 고정, IKER 보상 5항·종료 그대로.
- 달라지는 것: 로봇이 왼팔, 시작 상태가 **신발을 5 cm 이상 들고 쥔 상태**(원본 IKER 은 테이블 위 파지 자세에서 시작).

## 9. 평가·판정

- 1단계: 결정론 평가(512 env·첫 에피소드) 성공률, 성공 순간 q·손가락별 w_f, 들었다 놓침 비율, 받침 겹침 비율, 뱅크 수율.
  **첫 성공이 나오는 체크포인트에서 영상으로 파지 형태를 본다**(관찰 대조 7·9행 — 스칼라 성공 지표는 스스로를 감사하지 못한다).
- 1단계 게이트: ep 100 에 자유 들기 래치 비율 < 2 % 면 설계 문제로 멈추고 보고한다.
- 2단계: 기준 스펙 §9 평가 + 결정론 프로브(끝 5 cm). 비교 기준 = 오른팔 K1 ep250 26.8 %, ep750 평가값, 왼팔 K1.
- 실패 분해: 떨굼 / 시간초과 쥔 채 / 시간초과 놓침, 중심 오차 vs 회전(Kabsch).
