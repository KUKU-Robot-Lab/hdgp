# 보상 대조 — DexPour 논문 · agnostic/grasp_sensor · 우리(gripper/left/grasp_sensor fab)

**목적**: 이식이 충실한지 항목별로 확인한다. 08.26 fab_test41 기준.

## 1. 총보상 구조

| | DexPour (IROS 2025) | agnostic/grasp_sensor | **우리 t41** |
|---|---|---|---|
| 형태 | 스테이지 **합**, 이진 트리거 | 동일 | 동일 |
| 트리거 | λ→μ→ν→ρ (식 3~6) | λ→μ→ν→ρ | λ→μ→ν→ρ |
| 트리거 깊이 | ≤2 (μ = λ×접촉) | ≤2 | ≤2 |
| 무게이트 shaping | **없음** ← 사각지대 | `approach`+`contact` | `approach`+`contact` |

★논문은 `r_contact` 를 `μ·r_grasping` 안에 둬 **4지가 다 닿기 전에는 죽어 있다**.
 λ=1·μ=0("도착했지만 못 잡음") 구간의 보상이 0 이고, 우리 트랙은 보상 0 이 **조기 종료를
 최적**으로 만드는 실패를 겪었다(test6/test7: lifting 6.14→0, ep 130→13, 총보상 +34.9→−0.46).
 agnostic 이 실측으로 이 사각지대를 발견해 무게이트 shaping 으로 고쳤다. **고친 쪽을 이식했다.**

### ★★fab_test41-r2 사고 — 뺄셈 벌점이 총보상을 음수로 만들었다

agnostic 값(`0.08 × relu(기울기 − 8°)`)을 그대로 쓰니 전도 임계 60° 에서 **4.16** 이 나왔다.
approach 최대치 2.0 의 **두 배**다. 실측:

```
           approach  총보상      λ    턱-컵mm  tipped
ep0-51     -0.0690  -0.353  0.0358    148   0.952
ep153-204   0.1967   0.990  0.0000    242   0.000   ← 도망쳤다
```

총보상이 음수면 조기 종료가 최적이 된다. → **곱셈 감쇠**로 바꿔 approach 를 항상 비음수로:

```
approach = 2.0·exp(−4·d)·align·orient · (1 − 0.5·push_q) · (1 − 0.5·tilt_q)
```

컵 곁 최악 0.41 < 도망 0.76 이지만, **무게이트 `contact`(1.0)가 컵 곁에서만 나오므로**
0.41 + 1.0 = 1.41 > 0.76 이다. 접근이 최악의 경우에도 이긴다 —
무게이트 shaping 이 왜 필요한지가 여기서 다시 확인된다.
