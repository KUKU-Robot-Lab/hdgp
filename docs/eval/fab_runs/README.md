## 이 트랙에서 값비싸게 배운 것

1. **억제 항은 과제가 성립한 뒤에 켠다.** t14 가 jerk 를 ep0 부터 켜서 dwell 을 잃었다.
   판단 기준은 총보상 대비가 아니라 **그 시점에 살아 있는 신호 대비**다.
2. **지표가 좋아졌는데 영상이 이상하면 판정식부터 의심한다.** t11 은 `enclose` 0.824 로
   성공 런(0.804)보다 높았는데 컵 옆 85 mm 에 서 있었다. 게이트 기준을 `lateral` 로 바꿨다.
3. **통제 없는 파라미터 스윕은 거짓 원인을 만든다.** fabric damping 스윕이 "150 이 해답"을
   가리켰지만, 같은 파지 상태에서만 damping 을 바꾸니 20~200 전 구간 무영향이었다.
4. **합격 기준은 순변위로.** 순간 속도 0.07 m/s 는 서브밀리미터 솔버 버즈였다
   (순변위 2.3 mm/s). 게인·damping 어디에도 반응하지 않는 값을 기준으로 삼고 있었다.
5. **원본 ADR 파라미터의 어려운 끝값을 시작값으로 고정하지 말 것.** 속도 피드포워드
   (1→0 인데 0 고정), fabric damping(10→20 인데 20 고정), PD 게인 DR(통째로 누락) —
   같은 실수를 세 번 했다.
6. **`best` 와 `last` 는 항상 둘 다 잰다.** `nn/<task>.pth` 가 best, `nn/last_*.pth` 가 last.

## 합격 기준

컵–목표 < 30 mm · 기울기 ≤ 8° · 목표 10 cm 내 **순변위** < 0.05 m/s
보조: enclose ≥ 0.85 · drop% < 0.05 · 턱 높이가 파지대역(−82~−7 mm) 안

역대 최고는 t16 best(ep1812): 컵–목표 90 mm · 기울기 14.5° · 잔류 0.115 m/s · enclose 0.902.

### 경유한 보상 해킹 (ep190~2400) — 구조적 결함 3건

`closure` 가 상한의 74% 까지 오르는 동안 `contact_engage` 가 **정확히 0**이었다.
컵에서 170 mm 떨어진 허공에서 그리퍼를 85% 닫고 있었다. 분해:

```
align = 0.5·(1−tanh(along/0.030)) + 0.5·(1−tanh(lateral/0.060))   ← 곱이 아니라 합
  lateral 170 mm, along 0  →  align 0.500   (반쪽만 맞춰도 0.5 보장)
enclose = min(s_l,s_r)/half_width                                  ← 턱축 투영만, 측방 거리 조건 없음
JAW_ENCLOSE_FLOOR = 0.3                                            ← 바닥값까지 보장
closure = 5.0 × align × enclose × 닫힘정도                          ← 접촉 요구 없음. 최대 가중
```

세 결함이 겹쳐 "허공에서 닫기"가 상한 2.50 짜리 경로가 됐다. 같은 `enclose` 맹점에
속은 것이 **네 번째**다(fab_test11 85.5 mm 에 0.824 / t32 195 mm 에 0.852 / t38 closure).

### 남은 병목 — `PALM_BOX_Z` 하한

`lifting` 이 0 을 못 벗어난 직접 원인. **지령 z 가 ep1400~3900 내내 0.1601~0.1603 으로
박스 바닥(0.16)에 소수 넷째 자리까지 고정**이었다(x 는 0.220→0.399 로 자유롭게 움직였다).
0.16 은 파지대역 0.2475 보다 87 mm 아래라 정책이 쓸 이유가 없는 구간인데 gradient 만
그쪽으로 끌린다. z 를 올릴 압력은 `lifted`(스폰+6 mm)가 켜져야 생기고 그러려면 z 를
올려야 하는 **순환**이다. ep3900 대에 0.1638 로 겨우 4 mm 떨어졌다.
