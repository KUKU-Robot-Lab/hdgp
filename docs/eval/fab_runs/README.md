목표 이송 → 정지**시키는 트랙. 최종 목적은 양팔 물붓기다.

## 이 디렉토리

| 경로 | 내용 |

| `tfevents/fab_testN/env.yaml` | 그 런이 **실제로** 쓴 설정 덤프. 코드가 아니라 이걸 봐야 한다 |

## 이 트랙에서 값비싸게 배운 것

1. **억제 항은 과제가 성립한 뒤에 켠다.** t14 가 jerk 를 ep0 부터 켜서 dwell 을 잃었다.
   판단 기준은 총보상 대비가 아니라 **그 시점에 살아 있는 신호 대비**다.
2. **지표가 좋아졌는데 영상이 이상하면 판정식부터 의심한다.** t11 은 `enclose` 0.824 로
   성공 런(0.804)보다 높았는데 컵 옆 85 mm 에 서 있었다. 게이트 기준을 `lateral` 로 바꿨다.
3. **통제 없는 파라미터 스윕은 거짓 원인을 만든다.** fabric damping 스윕이 "150 이 해답"을
   가리켰지만, 같은 파지 상태에서만 damping 을 바꾸니 20~200 전 구간 무영향이었다.
4. **합격 기준은 순변위로.** 순간 속도 0.07 m/s 는 서브밀리미터 솔버 버즈였다
   (순변위 2.3 mm/s). 게인·damping 어디에도 반응하지 않는 값을 기준으로 삼고 있었다.
5. **원본 ADR 파라미터의 어려운 끝값을 시작값으로 고정하지 말 것.** 속도 피드포워드
   (1→0 인데 0 고정), fabric damping(10→20 인데 20 고정), PD 게인 DR(통째로 누락) —
   같은 실수를 세 번 했다.
6. **`best` 와 `last` 는 항상 둘 다 잰다.** `nn/<task>.pth` 가 best, `nn/last_*.pth` 가 last.

## 합격 기준

컵–목표 < 30 mm · 기울기 ≤ 8° · 목표 10 cm 내 **순변위** < 0.05 m/s
보조: enclose ≥ 0.85 · drop% < 0.05 · 턱 높이가 파지대역(−82~−7 mm) 안

역대 최고는 t16 best(ep1812): 컵–목표 90 mm · 기울기 14.5° · 잔류 0.115 m/s · enclose 0.902.
